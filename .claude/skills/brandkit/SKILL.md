# brandkit — Board de identidade num clique

## Entrega
Uma página HTML única (ou artifact) apresentando a identidade completa da marca, pronta para avaliação.

## Seções obrigatórias do board
1. **Essência** — 1 frase de posicionamento + 3 adjetivos da personalidade da marca.
2. **Logo tipográfico** — nome da marca em tipografia trabalhada (peso, espaçamento, eventual símbolo geométrico simples em SVG inline). Versões: principal, monocromática, invertida.
3. **Paleta** — cor primária, 1–2 de acento, neutros; cada uma com nome, HEX e OKLCH, exibidas em swatches com exemplos de uso.
4. **Tipografia** — família de display + família de texto (Google Fonts ou system stack), com escala demonstrada (H1→caption).
5. **Tom de voz** — 3 pares "somos / não somos" (ex.: "diretos, não secos") + 2 exemplos de frase da marca.
6. **Aplicações** — mockups simples em HTML/CSS: botão, card, post quadrado 1:1, cabeçalho de site.

## Regras
- Tudo autocontido (sem imagens externas; SVG e CSS inline).
- O board em si deve seguir a identidade que apresenta — ele é a primeira aplicação da marca.
- Coerência entre as seções: os adjetivos da essência devem ser visíveis na paleta e tipografia escolhidas.
